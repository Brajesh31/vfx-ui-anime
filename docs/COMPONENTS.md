# 🧩 Component index

This index lists the 82 custom element types currently present in the repository. Every component directory contains the implementation `index.js`, a standalone `demo.html`, and a component-specific `README.md` with its API and behavior.

The public custom-element prefix is `vfx-`.

## Component directory contract

For each component `<name>`, the expected directory is:

```text
components/<name>/
├── index.js       # standalone custom-element registration and implementation
├── demo.html      # isolated interactive example
└── README.md      # component API, behavior, examples and constraints
```

Use the component README as the authoritative API reference. This index is a directory, not a replacement for detailed property and event documentation.
