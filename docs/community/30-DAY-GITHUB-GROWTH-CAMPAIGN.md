**Suggested title:** ✨ Introducing VFX UI Anime: 82 Animated Web Components

**Body:**

Today I'm introducing **VFX UI Anime**, an open-source collection of 82 dependency-free, anime-inspired Web Components.

The idea is simple: everyday interface controls don't have to feel ordinary.

I wanted to explore what happens when practical UI controls meet expressive interaction design, spring-driven motion, illustrated impact effects and a consistent visual language.

### What's included?

- 82 browser-native custom elements.
- 83 interactive gallery examples.
- 82 standalone component demos.
- No runtime framework or third-party component dependency.
- Aggregate imports and individual component imports.
- MIT license.

### Explore the project

- 🌐 Live gallery: https://brajesh31.github.io/vfx-ui-anime/
- ⭐ Source repository: https://github.com/Brajesh31/vfx-ui-anime
- 📦 npm: https://www.npmjs.com/package/vfx-ui-anime
- 📖 Component index: https://github.com/Brajesh31/vfx-ui-anime/blob/main/docs/COMPONENTS.md

### Get started

```bash
npm install vfx-ui-anime
```

Register all components:

```js
import 'vfx-ui-anime';
```

Or register one component:

```js
import 'vfx-ui-anime/button';
```

The project uses browser-native Web Components. It does not provide React/Vue wrappers or named component classes.
