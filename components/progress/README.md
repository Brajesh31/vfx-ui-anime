# Progress component

A progress indicator with a completion response.

## Live demo
Open [demo.html](demo.html) to test the component in the library's design system.

## Installation
```html
<link rel="stylesheet" href="/styles.css">
<script defer src="/core.js"></script>
<script defer src="/components/progress/index.js"></script>
<vfx-progress label="Upload" value="68"></vfx-progress>
```

## Component details
- **Element:** `<vfx-progress>`
- **Category:** Feedback
- **Runtime dependencies:** None
