# Toast component

A temporary status message with a reusable show method.

## Live demo
Open [demo.html](demo.html) to test the component in the library's design system.

## Installation
```html
<link rel="stylesheet" href="/styles.css">
<script defer src="/core.js"></script>
<script defer src="/components/toast/index.js"></script>
<vfx-toast message="Your changes were saved">Show toast</vfx-toast>
```

## Component details
- **Element:** `<vfx-toast>`
- **Category:** Feedback
- **Runtime dependencies:** None
