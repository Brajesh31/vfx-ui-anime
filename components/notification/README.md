# Notification component

A notification bell with an unread count and clear action.

## Live demo
Open [demo.html](demo.html) to test the component in the library's design system.

## Installation
```html
<link rel="stylesheet" href="/styles.css">
<script defer src="/core.js"></script>
<script defer src="/components/notification/index.js"></script>
<vfx-notification count="3"></vfx-notification>
```

## Component details
- **Element:** `<vfx-notification>`
- **Category:** Feedback
- **Runtime dependencies:** None
