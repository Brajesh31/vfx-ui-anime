# 😀 VFX Emoji Picker

A compact emoji selector with search, a curated selection, and value events.

```html
<script src="/components/emoji-picker/index.js"></script>
<vfx-emoji-picker value="✨"></vfx-emoji-picker>
```

## API
- `value`: read or set the selected emoji.

## Events
- `select`: chosen emoji.
- `change`: updated value.

The built-in list is intentionally curated and can be extended in source for product-specific collections.
