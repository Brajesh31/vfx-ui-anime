# 🔐 Security Policy

## Supported versions
Security reports are accepted for the latest version on the default branch.

## Reporting a vulnerability
Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if available. If it is unavailable, contact the repository maintainer through the contact method listed on the GitHub profile.

Include:
- A clear description and impact.
- Steps to reproduce.
- A minimal proof of concept where safe.
- Browser and version details.

Do not include real user data, credentials or private tokens in reports.
