# 💬 Support

For usage questions:
1. Read the root README.
2. Check the component API in `docs/COMPONENTS.md`.
3. Review known limitations in `docs/ACCESSIBILITY.md`.
4. Search existing GitHub issues.
5. Open a question with a minimal reproduction if the issue persists.

Please include browser/version, expected behavior, actual behavior and a reduced example. Never post secrets or personal data.
