🧪 Live component examples

Integration cookbook

Every example below uses the component's implemented API. Eleven animated controls are self-contained. Like, Accordion, Segmented, and Notification use the separate core.js engine.

← Back to the component gallery · Read the integration guide

✨ Button

Click, wait for the save action, then call done() to show its success check.

Save changes

<vfx-button>Save changes</vfx-button>

🔔 Toggle

Read the boolean checked property on its change event.

<vfx-toggle label="Email notifications"></vfx-toggle>

🎚️ Slider and Progress

The slider's input event updates the progress bar from 0 to 1.

progress.set(Number(slider.value) / 100)

☑️ Checkbox

Read the checked state. Its label is the text inside the element.

Remember this device

<vfx-checkbox>Remember this device</vfx-checkbox>

🔘 Radio

Define choices with child option elements and read the selected value.

<vfx-radio><option>...</option></vfx-radio>

⌨️ Input

Listen for input and read the current value.

<vfx-input label="Email" type="email"></vfx-input>

🗂️ Tabs

The host application manages panels. Tabs reports the selected option in its change event.

Overview panel content
<vfx-tabs><option value="overview">Overview</option>...</vfx-tabs>

⭐ Rating

Select up to five stars. Click the selected star again to clear the score.

<vfx-rating label="Rate this recipe"></vfx-rating>

💬 Toast

Call show(message) when the host action succeeds.

Show toast
toast.show("Saved successfully!")

💡 Tooltip

Hover, focus, or tap the help control. Press Escape to dismiss the hint.

<vfx-tooltip text="Helpful hint"></vfx-tooltip>

💗 Like

This additional control uses core.js.

<vfx-like label="Like"></vfx-like>

📖 Accordion

Open and close the accessible disclosure region.

The original animated control set plus four additional UI components.
<vfx-accordion label="What is included?">...</vfx-accordion>

🎛️ Segmented

Select one option. Arrow keys move between available values.

<vfx-segmented><option>Day</option>...</vfx-segmented>

🔔 Notification

Activate the bell to clear its unread count.

<vfx-notification count="3"></vfx-notification>
